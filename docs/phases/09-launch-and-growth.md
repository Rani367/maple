# Phase 09: Launch And Growth

## Goal

Launch Maple in a way that maximizes GitHub stars.

## Deliverables

- Polished README.
- Demo GIF.
- Example maps.
- Install instructions.
- Launch checklist.
- Growth experiments.

## Implementation Tasks

1. Rewrite README around the one-line hook:
   - "Understand any repo in seconds."
2. Add installation:
   - Homebrew
   - Cargo
   - prebuilt binaries
3. Add demos:
   - local CLI
   - GitHub URL
   - web explorer
   - context pack
4. Generate example outputs for famous repos.
5. Add comparison table:
   - Repomix
   - GitDiagram
   - DeepWiki
   - Sourcegraph
6. Launch:
   - GitHub release
   - Hacker News
   - Reddit
   - X/Twitter
   - relevant Discords
7. Follow up with a browser extension or URL trick if traction appears.

## Star Growth Hooks

- One-command GitHub repo input.
- Gorgeous screenshot.
- Static HTML export.
- "No API key, fully local" trust signal.
- AI context pack as a bonus.
- Famous repo examples.

## Acceptance Criteria

- README explains the product in under 10 seconds.
- First GIF is compelling without reading text.
- Install works on macOS with one command.
- Launch issue tracker has good first issues.
- The repo has topics, description, and social preview image.
